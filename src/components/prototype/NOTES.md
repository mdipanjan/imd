# Visual direction prototype

Question: Which visual system should shape Dipanjan's personal technical publishing site?

Current verdict, 3 September 2026:

- Use A's landing/index experience: personal research notebook, current investigations, belief changes, and chronological writing.
- Use B's long-form article experience: a central reading canvas with a sticky left index and contextual revision notes on the right.
- Keep display type restrained. Field and Ledger remain viable; Manual was rejected and replaced with the more technical Workbench study.
- Interactive explanations should break wider than prose while keeping ordinary paragraphs at a comfortable reading measure.

The `H — Hybrid Journal` prototype combines the selected outer and inner pages. Rewrite the chosen system into production components, then remove the prototype route and controls.
